# Portfolio — Nalawi Woldeyohannes

Personal portfolio site, generated as static HTML from data files with plain Node.js
(no framework, no runtime dependencies).

```bash
npm test        # run the checks
npm run build   # generate dist/
npm start       # build and preview on http://localhost:3000
```

Requires Node.js 20 or newer. No `npm install` step is needed.

_Full documentation follows as the site is built._
